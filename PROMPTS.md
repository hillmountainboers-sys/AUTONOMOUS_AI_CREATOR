# 📌 Project Objective

The goal was to build an **Autonomous AI Creator** that no longer waits for human prompts after initialization.

Once initialized, the system should autonomously:

- Discover AI & Technology topics from live sources.
- Evaluate topics using an Editorial Decision Engine.
- Reject low-quality or duplicate topics.
- Remember previously published content.
- Generate consistent AI persona posts.
- Publish automatically over time.
- Expose only the required REST APIs.
